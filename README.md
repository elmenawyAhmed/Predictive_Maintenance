# Predictive Maintenance with XGBoost, IBM DB2, and IBM Maximo

## Overview

This project implements a predictive maintenance pipeline that uses historical asset and work order data from IBM Maximo to predict potential equipment failures within a 30-day horizon.

The pipeline extracts operational data from IBM DB2, engineers asset-level features, trains an XGBoost classification model, estimates failure probabilities, assigns asset risk levels, and stores prediction results for further analysis.

## Key Features

- **Data Extraction:** Retrieve asset, work order, failure history, and preventive maintenance data from IBM DB2.
- **Feature Engineering:** Calculate work order statistics, Mean Time Between Failures (MTBF), Mean Time To Repair (MTTR), asset age, and preventive maintenance indicators.
- **Temporal Dataset Construction:** Build historical asset snapshots for model training and evaluation.
- **Data Validation:** Check dataset integrity, duplicate records, and potential feature leakage.
- **Machine Learning:** Train an XGBoost classifier with class-imbalance handling.
- **Probability Calibration:** Apply Platt scaling when the calibration dataset supports it.
- **Model Evaluation:** Calculate metrics including PR-AUC, ROC-AUC, Brier score, precision, recall, and F1-score.
- **Explainable AI:** Use SHAP to analyze global feature importance and model behavior.
- **Risk Classification:** Categorize assets into HIGH, MEDIUM, and LOW risk levels.
- **Database Integration:** Write daily asset failure predictions to IBM DB2.
- **Export:** Save prediction results as a CSV file and the trained model in JSON format.

## Project Workflow

1. Connect to IBM DB2.
2. Extract asset and work order history from IBM Maximo.
3. Generate historical snapshots and engineer predictive features.
4. Validate the dataset and check for potential data leakage.
5. Train and evaluate the XGBoost model using chronological data splits.
6. Calibrate predicted probabilities when possible.
7. Analyze feature contributions using SHAP.
8. Generate asset failure probabilities and risk categories.
9. Save the trained model, export predictions, and write results to DB2.

## Installation

Clone the repository:

```bash
git clone https://github.com/elmeanwy-ahmed/Predictive_Maintenance.git
cd Predictive_Maintenance
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Configure your DB2 connection using environment variables or another secure configuration method. Do not commit database credentials to source control.

## Execution

Open the notebook in Jupyter:

```bash
jupyter notebook predictive_maintenance_v5.1.ipynb
```

Run the notebook in an environment that has the required database connectivity and permissions.

**Note:** This pipeline is database-dependent and cannot run end-to-end without compatible IBM Maximo data and an authorized DB2 connection.
